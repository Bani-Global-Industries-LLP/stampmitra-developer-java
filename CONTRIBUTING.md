# Contributing

Thanks for helping improve the StampMitra Java SDK.

## Setup

Requires JDK 11 or newer (CI runs 11, 17 and 21), Maven 3.6.3+ and, for the conformance suite, Node 18+.

```bash
mvn -B verify                        # compile with -Xlint:all -Werror, checkstyle, tests, javadoc, jacoco
node scripts/generate.mjs --check    # generated sources are up to date with spec/openapi.json
node scripts/readme-snippets.mjs --check
mvn -q test -Dtest=SpecCoverageTest  # every operation in spec/openapi.json must have an SDK method
scripts/run-examples.sh              # compile and run every example against the mock server
```

## Conformance suite

`src/test/java/in/stampmitra/sdk/conformance` starts `scripts/mock-server.mjs` of the spec repo on a free port and exercises all
31 operations, error mapping, retry and idempotency sequences, timeouts, dropped connections, pagination, and the shared
webhook and validator vectors. It needs a checkout of the spec repo:

```bash
git clone https://github.com/Bani-Global-Industries-LLP/stampmitra-developer-openapi ../stampmitra-developer-openapi
# or: export STAMPMITRA_SPEC_DIR=/path/to/stampmitra-developer-openapi
mvn -B verify
```

The suite is skipped when the spec repo or Node is missing, unless `CONFORMANCE_REQUIRED=1` (CI sets it), where it fails instead.
CI checks out the spec repo's default branch, so that repository needs a `main` branch to exist.

`src/test/resources/fixtures/*.json` and `spec/openapi.json` are copies of files in the spec repo; the suite fails if they drift, so refresh
them when the spec repo changes.

## Generated code

`models/`, `requests/` and `resources/` (except `LogsResource`, `LogsParams`, `PaymentsResource`, `WebhooksResource`) are generated by
`node scripts/generate.mjs` from `spec/openapi.json` and a small resource table inside the script. Edit the script, not the output.
`examples/.../ReadmeSnippets.java` is generated from the Java blocks of `README.md` by `node scripts/readme-snippets.mjs`.

## Guidelines

- Java 11 source and API level (`--release 11`): no records, `var` in lambdas, text blocks or `List.toList()`.
- Runtime dependencies stay at Jackson only. No Lombok, no annotation processors, no reflection-based magic on the public API.
- Every public type and method needs Javadoc; the build fails on Javadoc warnings and on any javac lint warning.
- Never log or commit real keys or personal data; unit tests use a fake transport or loopback servers, never the network.
- When the API changes: copy the new `openapi.json`, run `node scripts/generate.mjs`, add what the coverage test asks for.
- Update `CHANGELOG.md` under *Unreleased*.
- By contributing you agree your work is licensed under the MIT license.

Security issues: see [SECURITY.md](SECURITY.md), do not open a public issue.
